## 🎉 v3.0重大更新

### 核心变更
1. ⭐ **工作项统一管理**: 取消Story层，改用工作项（WorkItem）
2. ⭐ **多类型工作支持**: 需求、Bugfix、技术债、非功能需求、优化、调研
3. ⭐ **团队-模块绑定**: 明确团队责任范围，工作项自动路由
4. ⭐ **产能计量改变**: 从Story Points改为工作量（小时）

### v3.0对项目管理的影响
- ✅ **迭代计划更灵活**: 可混合规划多种工作项类型
- ✅ **工作量更准确**: 基于小时的估算更精确
- ✅ **团队协作更清晰**: 模块责任明确，减少跨团队协调
- ✅ **进度跟踪更完整**: Bugfix和技术债纳入迭代跟踪
