## 🎯 项目概述

### 改造目标

引入**车型项目**和**领域项目**管理体系，完善从项目规划到迭代交付的完整研发价值流。

### 核心变更

```
旧架构 (v2):
Product → Feature → Module → PI Planning → Sprint

新架构 (v3):
VehicleProject → DomainProject → Product → PI Planning → 
ProjectBacklog → TeamBacklog → Sprint
```
