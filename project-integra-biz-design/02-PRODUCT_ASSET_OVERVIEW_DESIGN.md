# 产品资产管理一页视图设计

> **文档版本**: v1.0  
> **创建日期**: 2025-01-09  
> **设计目标**: 为产品经理提供一页式产品资产全景视图，涵盖产品线、产品、版本、特性、模块及其在项目中的状态

---

## 一、设计背景与目标

### 1.1 用户角色与痛点

#### 目标用户
- **产品经理**（Primary）：需要全局掌握产品资产和项目应用状态
- **产品线经理**：需要跨产品的资产视图和健康度监控
- **技术架构师**：需要了解资产复用情况和模块分布

#### 核心痛点
1. ❌ **信息分散**：产品、特性、模块、版本分散在不同页面，需要多次跳转
2. ❌ **状态不明**：不清楚产品在不同项目中的应用状态和开发进度
3. ❌ **缺少全景**：无法快速了解产品线下所有产品的整体健康度
4. ❌ **关系不清**：产品、版本、项目之间的关联关系不够清晰
5. ❌ **决策困难**：缺少数据支撑，难以快速做出版本规划和资源分配决策

## 三、各区域详细设计

### 3.1 区域1：产品线卡片区

#### 3.1.1 设计目标
- 快速概览所有产品线
- 提供产品线级别的统计信息
- 支持点击切换查看不同产品线

#### 3.1.2 卡片设计

```
┌───────────────────────┐
│  🚗 智能驾驶           │  ← 产品线图标和名称
├───────────────────────┤
│  产品: 3              │  ← 统计信息
│  版本: 12 (8进行中)   │
│  特性: 45             │
│  模块: 118            │
├───────────────────────┤
│  📊 健康度: ●●●●○ 80% │  ← 健康度指标
├───────────────────────┤
│  关联项目: 5          │  ← 应用情况
│  活跃开发: 3          │
└───────────────────────┘
```

**交互行为**：
- **点击卡片**：在区域2中展开该产品线的产品树
- **悬停效果**：显示更多统计信息（需求数、工作项数）
- **右键菜单**：
  - 查看产品线详情
  - 创建新产品
  - 导出产品线报告

#### 3.1.3 健康度计算规则

```typescript
健康度 = (
  版本按时交付率 * 0.3 +
  资产复用率 * 0.2 +
  需求覆盖率 * 0.2 +
  模块完整度 * 0.15 +
  文档完整度 * 0.15
) * 100%

健康度等级：
- ●●●●● 90-100%：优秀（绿色）
- ●●●●○ 75-89%：良好（蓝色）
- ●●●○○ 60-74%：一般（黄色）
- ●●○○○ 40-59%：风险（橙色）
- ●○○○○ 0-39%：危险（红色）
```

### 3.3 区域3：产品-项目状态矩阵

#### 3.3.1 设计目标
- 快速查看产品在不同项目中的应用情况
- 识别同一产品在多个项目中的版本差异
- 发现项目间的版本协同机会

#### 3.3.2 矩阵设计

**表头设计**：

```
┌────────────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│                │ 项目A   │ 项目B   │ 项目C   │ 项目D   │ 项目E   │
│ 产品 / 项目     │ (L3项目)│(L2+项目)│(L4项目) │(座舱项目)│(EE项目) │
│                │ 车型X   │ 车型Y   │ 车型Z   │ 车型X   │ 车型Y   │
├────────────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
```

**单元格内容设计**：

```
单元格状态：
1. ✅ v2.5.0        - 已集成，显示版本号（绿色）
2. 🚧 v3.0.0 (60%)  - 开发中，显示版本号和进度（蓝色）
3. 📝 v3.5.0        - 已计划，显示版本号（灰色）
4. ⚠️ v2.0.0       - 存在风险，显示版本号（橙色）
5. ❌ v1.8.0        - 已废弃/停止（红色）
6. -               - 未使用（空白）
```

**交互行为**：
- **点击单元格**：跳转到该产品在该项目中的详情页（领域项目详情 + 产品版本筛选）
- **悬停效果**：显示Tooltip
  ```
  产品: 智能驾驶OS v3.0.0
  项目: 智驾L3项目 (PI-2025-Q1)
  状态: 开发中
  进度: 60% (45/75)
  负责团队: 感知团队、决策团队
  风险: 无
  [点击查看详情]
  ```
- **颜色编码**：根据状态和健康度显示不同背景色

**筛选与排序**：

### 5.2 关键计算逻辑

#### 计算1：产品在项目中的状态

```typescript
function getProductStatusInProject(productId, versionId, projectId) {
  // 1. 查询项目待办中是否包含该产品版本的需求
  const projectBacklog = getProjectBacklog(projectId)
  const relatedWorkItems = projectBacklog.items.filter(
    item => item.productVersionId === versionId
  )
  
  // 2. 计算状态
  if (relatedWorkItems.length === 0) {
    return { status: 'not_used', version: null }
  }
  
  // 3. 计算进度
  const total = relatedWorkItems.length
  const completed = relatedWorkItems.filter(
    item => item.status === 'completed'
  ).length
  const progress = (completed / total) * 100
  
  // 4. 判断健康度
  let health = 'good'
  if (progress < 30 && isOverdue(relatedWorkItems)) {
    health = 'at_risk'
  }
  
  return {
    status: progress === 100 ? 'integrated' : 'in_progress',
    version: versionId,
    progress,
    health,
    workItems: relatedWorkItems.length
  }
}
```

#### 计算2：资产复用率

```typescript
function calculateAssetReuseRate() {
  // 获取所有模块
  const allModules = getAllModules()
  
  // 计算每个模块被多少个项目使用
  const moduleUsageMap = {}
  allModules.forEach(module => {
    const projects = getProjectsUsingModule(module.id)
    moduleUsageMap[module.id] = projects.length
  })
  
  // 计算复用率
  const totalModules = allModules.length
  const reusedModules = Object.values(moduleUsageMap).filter(
    count => count > 1
  ).length
  
  return (reusedModules / totalModules) * 100
}
```
