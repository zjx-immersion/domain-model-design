# 项目管理一页视图设计

> **文档版本**: v1.0  
> **创建日期**: 2025-01-09  
> **设计目标**: 为项目经理提供一页式项目管理全景视图，涵盖车型项目、领域项目、PI Planning、Sprint及其与车型里程碑的对齐关系

---

## 一、设计背景与目标

### 1.1 用户角色与痛点

#### 目标用户
- **项目经理**（Primary）：需要全局掌握项目进度、风险和资源分配
- **车型项目经理**：需要协调多个领域项目，确保车型里程碑按时交付
- **PMO（项目管理办公室）**：需要跨项目的数据汇总和决策支持

#### 核心痛点
1. ❌ **项目信息碎片化**：车型项目、领域项目、PI、Sprint分散在不同页面
2. ❌ **进度难追踪**：无法快速了解项目整体进度和关键路径
3. ❌ **里程碑对齐难**：车型里程碑与PI/Sprint的对齐关系不清晰
4. ❌ **风险不可见**：项目风险和阻塞点缺少预警机制
5. ❌ **资源协调难**：跨项目的资源冲突和依赖关系难以管理

## 三、各区域详细设计

### 3.1 区域1：车型项目看板

#### 3.1.1 设计目标
- 快速概览所有车型项目
- 提供车型项目级别的关键信息
- 支持点击查看车型项目详情

#### 3.1.2 卡片设计

```
┌────────────────────────────┐
│  🚗 车型X                   │  ← 车型名称
│  智能驾驶L3量产项目         │  ← 项目简称
├────────────────────────────┤
│  SOP日期: 2025-Q2          │  ← 关键里程碑
│  当前阶段: 系统集成测试      │
├────────────────────────────┤
│  📦 领域项目: 5             │  ← 统计信息
│  📅 PI Planning: 12         │
│  🏃 活跃Sprint: 8           │
├────────────────────────────┤
│  📊 整体进度: ████████░░ 75%│  ← 进度条
├────────────────────────────┤
│  ⚠️ 风险: 3个高风险          │  ← 风险预警
│  🔴 阻塞: 1个关键阻塞        │
├────────────────────────────┤
│  👥 核心团队: 8个团队        │  ← 资源信息
│  🎯 交付产品: 3个            │
└────────────────────────────┘
```

**卡片状态颜色**：
- 🟢 **绿色边框**：进度正常，无风险（进度 ≥ 计划进度）
- 🟡 **黄色边框**：轻微延期，有一般风险（进度差距 < 10%）
- 🟠 **橙色边框**：明显延期，有高风险（进度差距 10-20%）
- 🔴 **红色边框**：严重延期，存在关键阻塞（进度差距 > 20%）

**交互行为**：
- **点击卡片**：在区域3中展开该车型项目的所有领域项目
- **悬停效果**：显示更多信息（团队列表、关键里程碑、最新动态）
- **右键菜单**：
  - 查看车型项目详情
  - 查看里程碑时间轴
  - 创建新领域项目
  - 导出项目报告

- **点击时间块**：在区域3中显示该项目/PI的详细信息
- **展开/折叠**：点击项目前的 `▶/▼` 展开/折叠PI和Sprint
- **高亮关联**：悬停某个时间块，高亮其依赖和被依赖的项目

### 6.2 关键计算逻辑

#### 计算1：车型项目整体进度

```typescript
function calculateVehicleProjectProgress(vehicleProjectId) {
  // 1. 获取所有领域项目
  const domainProjects = getDomainProjects(vehicleProjectId)
  
  // 2. 计算每个领域项目的权重（基于工作量或优先级）
  const projectWeights = domainProjects.map(project => ({
    id: project.id,
    weight: project.workItemCount / totalWorkItems,
    progress: calculateDomainProjectProgress(project.id)
  }))
  
  // 3. 加权平均计算整体进度
  const overallProgress = projectWeights.reduce(
    (sum, p) => sum + (p.progress * p.weight),
    0
  )
  
  return Math.round(overallProgress)
}
```

function predictMilestoneDelay(milestoneId) {
  const milestone = getMilestone(milestoneId)
  const relatedProjects = getRelatedProjects(milestoneId)
  
  // 1. 计算关键路径上的项目进度
  const criticalPathProjects = relatedProjects.filter(
    p => p.isCriticalPath
  )
  
  // 2. 基于当前速度（Velocity）预测完成时间
  const predictions = criticalPathProjects.map(project => {
    const velocity = calculateVelocity(project.id)
    const remainingWork = project.totalWork - project.completedWork
    const estimatedDays = remainingWork / velocity
    const predictedDate = addDays(new Date(), estimatedDays)
    return predictedDate
  })
  
  // 3. 取最晚的预测日期作为里程碑预测日期
  const latestPrediction = Math.max(...predictions)
  
  // 4. 计算延期天数
  const delayDays = dateDiff(milestone.plannedDate, latestPrediction)
  
  return {
    predictedDate: latestPrediction,
    delayDays,
    riskLevel: delayDays > 10 ? 'high' : delayDays > 5 ? 'medium' : 'low'
  }
}
