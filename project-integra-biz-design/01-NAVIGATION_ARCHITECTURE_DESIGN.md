# 导航架构设计 v3.0

> **文档版本**: v3.0  
> **创建日期**: 2025-01-09  
> **设计目标**: 基于V3业务架构和研发价值流，重构平台导航体系，提升用户体验和业务协同效率

---

## 一、设计背景与目标

### 1.1 当前导航架构存在的问题

#### 问题1：缺少核心业务视角入口
- ❌ 缺少"产品资产视角"的统一入口（当前资产、需求分散在不同菜单）
- ❌ 缺少"项目视角"的全局管理入口（项目、PI、Sprint分散）
- ❌ 无法快速看到产品在不同项目中的状态全景

#### 问题2：导航层级与业务流程不匹配
- ❌ 当前导航是按功能模块分类（资产、需求、项目、Sprint等）
- ✅ 但实际业务流程是：**产品规划 → 项目立项 → PI Planning → 迭代执行 → 交付**
- ❌ 导航没有体现这个价值流的逻辑

#### 问题3：角色工作场景不清晰
- **产品经理**：需要跨多个菜单（资产、需求、版本）才能完成产品管理
- **项目经理**：需要在项目、PI、Backlog之间频繁切换
- **团队Leader**：需要在团队待办、Sprint、DevOps之间跳转
- **开发人员**：迭代工作分散在多个入口

#### 问题4：缺少关键的一页视图
- ❌ 没有"产品健康度仪表盘"（产品在各项目中的状态）
- ❌ 没有"项目进度全景图"（项目、PI、迭代的整体进度）
- ❌ 没有"团队工作台"（团队当前迭代的工作概览）

## 二、V3.0 导航架构设计原则

### 2.1 核心设计原则

#### 原则1：业务视角优先（Role-Based Navigation）
```
导航设计 = 角色工作场景 + 价值流阶段 + 功能模块
```

- **一级导航**：按业务视角/角色工作场景组织（工作台、产品中心、项目中心、团队工作台）
- **二级导航**：按价值流阶段或功能模块组织
- **三级导航**：具体功能页面

#### 原则2：一页视图（Single Page Dashboard）
每个核心业务视角都应有一个"一页总览"：
- 📊 **产品中心首页**：产品资产全景（产品线 → 产品 → 版本 → 特性 → 模块 + 项目状态）
- 📊 **项目中心首页**：项目管理全景（车型项目 → 领域项目 → PI → Sprint + 进度可视化）
- 📊 **团队工作台首页**：团队迭代工作全景（当前Sprint + 待办 + 任务 + 进度）

#### 原则3：快速导航与上下文保持
- 🔗 **面包屑导航**：始终显示当前位置的完整路径
- 🔗 **关联跳转**：相关实体间支持一键跳转（如：需求 → 工作项 → Sprint → 团队）
- 🔗 **返回上一级**：每个详情页都能快速返回列表页

#### 原则4：权限与个性化
- 🔒 不同角色看到不同的导航菜单（基于权限）
- 🎨 支持自定义常用功能到"我的工作台"

## 四、导航跳转策略与逻辑

### 4.1 上下文导航（Contextual Navigation）

#### 策略1：产品视角的上下文跳转

```
产品资产全景页
  ├─ 点击产品线卡片 → 产品线详情页
  │   ├─ 点击产品 → 产品详情页
  │   │   ├─ 点击版本 → 产品版本详情
  │   │   ├─ 点击特性 → 特性详情（筛选此产品）
  │   │   ├─ 点击模块 → 模块详情（筛选此产品）
  │   │   └─ 点击"在项目中的状态" → 跳转到项目中心（筛选此产品）
  │   │
  │   └─ 点击特性 → 特性详情
  │       ├─ 点击关联需求 → 需求详情
  │       ├─ 点击关联模块 → 模块详情
  │       └─ 点击"实现状态" → 跳转到项目/PI（筛选此特性）
  │
  └─ 点击"项目状态矩阵" → 跳转到项目全景图（带产品筛选）
```

**关键规则**：
- ✅ 保持产品上下文：跳转到其他视图时，带上产品ID作为筛选条件
- ✅ 面包屑导航：始终显示完整路径（产品线 > 产品 > 特性）
- ✅ 快速返回：每个详情页顶部有"返回上一级"按钮

---

#### 策略2：项目视角的上下文跳转

```
项目全景图页
  ├─ 点击车型项目 → 车型项目详情
  │   ├─ 点击领域项目 → 领域项目详情
  │   │   ├─ 点击产品版本 → 跳转到产品中心（产品版本详情）
  │   │   ├─ 点击PI Planning → PI Planning工作区
  │   │   │   ├─ 点击特性包 → 特性包详情
  │   │   │   ├─ 点击团队 → 团队待办详情
  │   │   │   └─ 点击Sprint → Sprint详情
  │   │   │
  │   │   ├─ 点击项目待办 → 项目待办详情
  │   │   │   ├─ 点击工作项 → 工作项详情
  │   │   │   └─ 点击"分配到团队" → 团队待办详情
  │   │   │
  │   │   └─ 点击"产品信息" → 跳转到产品中心（产品详情）
  │   │
  │   └─ 点击里程碑 → 里程碑详情（展示关联的PI和Sprint）
  │
  └─ 点击"PI时间轴" → PI Planning列表（按时间排序）
```

**关键规则**：
- ✅ 保持项目上下文：跳转时带上项目ID和车型项目ID
- ✅ 双向导航：项目 ↔ 产品、项目 ↔ 需求、项目 ↔ 工作项
- ✅ 时间轴导航：支持在时间轴上点击，跳转到对应的PI或Sprint

### 4.3 面包屑导航规范

#### 规范1：面包屑格式

```
首页 > 一级菜单 > 二级菜单 > 当前页 > [实体名称]

示例：
首页 > 产品中心 > 领域产品 > 智能驾驶OS > 版本 > v2.5.0

首页 > 团队工作台 > Sprint管理 > Sprint 1 - NOA功能开发
```

#### 规范2：面包屑行为

- 每一级都可点击，快速返回
- 当前页不可点击，显示为灰色
- 实体名称（如产品名、项目名）显示为高亮

#### 规范3：面包屑上下文

- 跨视角跳转时，面包屑重置
- 同视角内跳转时，面包屑累加
- 支持"返回上一页"按钮（浏览器历史）
